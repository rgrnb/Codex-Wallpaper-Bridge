# Codex Wallpaper Bridge 使用说明

适用版本：**0.1.0 Windows x64 适配验证版**  
更新日期：2026 年 10 月 15 日

Codex Wallpaper Bridge 将 Wallpaper Engine 当前选中的壁纸显示在已连接的 Codex 窗口内。你继续在 Wallpaper Engine 中选择壁纸，在 Bridge 中调整背景效果与性能。

当前已验证 Video、Scene、Web、Application 四类壁纸的接入；兼容性取决于应用版本和具体壁纸项目。完整验证范围见文末“兼容范围”。

## 1. 第一次使用

1. **启动 Wallpaper Engine，选择一张壁纸**，确认它正在桌面播放。
2. 运行 [CodexWallpaperBridge-Setup-0.1.0.exe](../dist/CodexWallpaperBridge-Setup-0.1.0.exe)，按需勾选“创建桌面快捷方式”和“随 Windows 登录启动”，点击“安装”。这两个选项默认关闭。
3. 安装完成后，从 Windows 开始菜单打开 **Codex Wallpaper Bridge**。
4. 在 Bridge 设置中点击 **“以连接模式启动 Codex”**。在新打开的官方 Codex 窗口中完成正常登录（如果需要）。
5. 勾选 **“启用动态背景”**，点击 **“保存并应用”**。
6. 等待状态变成 **“壁纸已同步”**，在连接模式的 Codex 窗口中查看背景。设置顶部还会显示壁纸类型、来源、已连接窗口数量和有效 FPS 上限。
7. 关闭设置窗口后，Bridge 继续在系统托盘运行。双击托盘图标可以再次打开设置。

**已有 Codex 窗口可能没有可连接的端口，因此首次使用请通过 Bridge 的按钮启动。** 连接模式使用独立配置，原有 Codex 窗口可以保留；原配置的登录状态和设置不会自动复制到独立配置。退出 Bridge 后，这个官方 Codex 窗口仍可继续使用。

首次使用无需勾选两个“允许……”高级选项。

## 2. 安装方式与运行条件

需要 Windows x64、已安装的官方 Codex 和 Wallpaper Engine。使用 Web 壁纸还需要 Microsoft Edge。安装包自带运行环境，日常使用无需安装 Node.js 或编译工具，也无需管理员权限。

| 文件 | 用途 | 使用方式 |
| --- | --- | --- |
| `CodexWallpaperBridge-Setup-0.1.0.exe` | 日常安装使用 | 安装到当前用户，提供开始菜单与卸载入口 |
| `CodexWallpaperBridge-0.1.0-win-x64.zip` | 便携使用 | 完整解压到固定文件夹，运行其中的 `CodexWallpaperBridge.exe` |
| `CodexWallpaperBridge-0.1.0-source.zip` | 查看或编译源码 | 普通使用不需要 |

便携版应保留全部解压文件，不要只移动 EXE，也不要直接在压缩包内运行。若启用随 Windows 登录启动，请保持所在文件夹的位置不变。

安装版的逻辑安装位置为 `%LOCALAPPDATA%\Programs\CodexWallpaperBridge`。MSIX 环境可能将本地应用数据重定向到实际的 `LocalCache` 目录。

## 3. 调整透出度与背景效果

修改设置后，点击 **“保存并应用”** 才会生效。拖动滑块本身不会立即应用。

| 设置 | 范围 | 默认值 | 效果 |
| --- | --- | --- | --- |
| 壁纸不透明度 % | 0～100 | **60** | 数值越大，壁纸越明显；0 时壁纸不可见 |
| 模糊 px | 0～30 | **0** | 数值越大，背景越模糊 |
| 亮度 % | 10～200 | **100** | 100 为原始亮度，降低可减轻背景对阅读的干扰 |
| 对比度 % | 10～200 | **100** | 100 为原始对比度 |

想让壁纸透出得更多，先将“不透明度”从 60 调到 70，再保存，根据文字可读性继续微调。这些效果只作用于壁纸背景。

点击 **“重置效果”** 会把四个滑块恢复为 60、0、100、100，随后仍需点击 **“保存并应用”**。它不会重置性能策略或切换 Wallpaper Engine 壁纸。

## 4. 流畅度与画质设置

默认使用 **平衡模式、60 FPS 上限、自动调整帧率开启**。这可作为视频壁纸的起始设置；希望保留清晰细节时，模糊保持 0。

| 性能策略 | 模式最高 FPS | Video 视频壁纸 | Scene / Web / Application 壁纸 |
| --- | --- | --- | --- |
| 性能模式 | 30 | 保留原视频编码与分辨率，限制绘制帧率 | 较小的图像尺寸与较低的图像编码品质 |
| 平衡模式 | 60 | 保留原视频编码与分辨率 | 中等图像尺寸与编码品质，默认选项 |
| 画质模式 | 60 | 保留原视频编码与分辨率 | 更大的图像尺寸与较高的图像编码品质 |

**视频不进行转码，也不生成低清副本。** 调低 FPS 上限会影响运动流畅度，不改变源视频编码品质。非视频类型使用图像传输路径，性能策略会影响其图像品质；对这三类优先看重清晰度时，可选“画质模式”。

“有效 FPS 上限”由所选模式、你填写的 FPS 上限以及实际负载共同决定。它是绘制上限，**不是实际测得的播放帧率**；实际流畅度还取决于源素材帧率、Wallpaper Engine 是否持续输出画面和电脑负载。

- “FPS 上限”可设置为 1～60。例如性能模式即使填写 60，有效上限也不会超过 30。
- 开启“根据实际负载自动调整帧率”后，检测到负载过高会降低帧率，不会为此自动调低空间画质参数。
- 如需排查自动降帧，可临时取消该选项并保存，观察流畅度与资源占用，再决定是否保留。
- 多个窗口不会仅因数量增加就自动降帧，但每个视频窗口仍会产生解码与绘制负载。
- 最小化或被判定不可见的连接窗口会暂停自身背景工作，恢复可见后同步当前壁纸。

参考机器的双窗口 4K 视频短时实测接近 60 FPS；这不是对所有设备、所有壁纸或长时间运行的帧率保证。

## 5. 切换壁纸、多显示器与声音

### 切换壁纸

在 Wallpaper Engine 中选择新壁纸即可。Bridge 会自动检测切换；无需在 Bridge 中重复导入文件。切换时可能短暂显示“正在准备新壁纸”。

背景按原始比例居中铺满 Codex 内部区域，超出部分会裁切，包含侧栏、主区域和输入区。Windows 原生标题栏不在覆盖范围内。

### 多显示器与多窗口

“来源显示器（从 0 起）”默认是 **0，即 Monitor0**。如果同步到的不是预期壁纸，按 Wallpaper Engine 的显示器分配调整这个数值，再保存。这里的编号不一定与 Windows 显示设置中的“1、2”相同。

所有已连接的 Codex 窗口共用一个来源；当前没有为每个窗口单独选择壁纸的功能。当前 Scene 实机验证范围是 Monitor0 上可明确识别的单个渲染器，其他布局仍需验证。

### 声音

**Bridge 内的背景始终静音。** 如果仍听到壁纸声音，可能来自 Wallpaper Engine 原本的桌面播放，可在 Wallpaper Engine 中自行调整。Bridge 不修改系统音量或桌面壁纸的音频设置。

## 6. 托盘、开机启动与恢复外观

托盘图标位于 Windows 任务栏通知区域，也可能收在“显示隐藏的图标”中。

| 托盘菜单 | 操作结果 |
| --- | --- |
| 设置与状态 | 打开设置窗口；双击托盘图标也可以打开 |
| 启用背景 | 使用已保存设置启用背景 |
| 恢复官方外观 | 立即移除 Bridge 背景并关闭背景启用状态，Bridge 继续运行 |
| 导出诊断 | 生成本地诊断文件 |
| 退出并恢复 | 恢复外观并退出 Bridge |

设置窗口也提供“恢复官方外观”。恢复后若想继续使用，可在托盘选择“启用背景”，或者勾选“启用动态背景”再保存。

**关闭设置窗口只会隐藏到托盘。** 需要完全退出时，使用“退出并恢复”。Bridge 正常退出会清理自身背景；控制器意外中断后，页面通常会在约 15～18 秒内自动清理。如果仍有残留，可重新打开受影响的 Codex 窗口。

启用“随 Windows 登录启动（仅当前用户）”并保存后，Bridge 会在该用户登录 Windows 时运行。此选项只启动 Bridge；Wallpaper Engine 和连接模式 Codex 仍需正常启动。

## 7. 状态提示与常见问题

| 状态或现象 | 含义与处理 |
| --- | --- |
| 背景已关闭 | 勾选“启用动态背景”并保存，或从托盘启用 |
| 正在等待应用连接 | 确认 Wallpaper Engine 已运行，再点击“以连接模式启动 Codex” |
| 正在准备新壁纸 | 正在加载或等待渲染画面；首次加载稍候再观察 |
| 壁纸已同步 | 当前来源已应用到连接窗口 |
| 背景已暂停 | 恢复窗口可见状态，并检查 Wallpaper Engine 的暂停条件 |
| 已恢复官方外观，正在重连 | Bridge 正在尝试恢复；持续出现时导出诊断。达到重试上限后，更换来源或修正环境，再保存设置重试 |
| 当前适配尚未验证或不兼容 | 当前版本、项目接口或画面格式未通过检查；查看详情并选择兼容项目或等待适配更新 |
| 同步到另一台显示器的壁纸 | 检查“来源显示器（从 0 起）”，修改后保存 |
| 状态已同步，但壁纸太淡或不可见 | 检查不透明度是否为 0、亮度是否过低，并确认正在查看已连接的 Codex 窗口 |
| FPS 上限设置为 60，但有效上限只有 30 | 检查是否选择性能模式，或自动负载调整是否已触发 |
| Scene / Application 停在一帧 | 检查原桌面壁纸是否也暂停，以及 Wallpaper Engine 对最大化、全屏应用等情形的播放规则 |
| 设置窗口关了，背景还在 | 属于正常托盘驻留；通过“退出并恢复”完全退出 |
| 尚未配置发布源 | 默认没有公共更新源，不影响壁纸功能 |

两个“允许候选 Codex 适配器 / 允许实验性渲染适配”选项用于开发验证。它们不能保证兼容性，日常使用保持关闭。

## 8. 导出诊断与数据位置

遇到持续故障时，在设置中点击 **“导出诊断”**，按弹窗显示的位置查找 `diagnostics.json`。托盘菜单也能触发导出。

Bridge 数据的逻辑位置为 `%LOCALAPPDATA%\CodexWallpaperBridge`，包含偏好、日志、诊断、更新记录，以及连接模式 Codex 使用的独立配置目录。MSIX 环境可能重定向到实际的 `LocalCache` 位置。

诊断导出包含运行状态、版本、来源元数据和性能等信息，不包含聊天内容、登录资料、API key 或工作文件。文件保留在本地，不会自动上传；分享前可自行查看。排查时可按需开启“Debug 诊断”，完成后关闭并保存。

**不要把整个数据目录当作临时缓存清空。** 其中的 `codex-profile` 是独立 Codex 配置，可能包含你的登录状态和个人设置。

## 9. 更新与卸载

### 更新

当前默认未配置公共发布源，显示“尚未配置发布源”属于正常状态。

如果发行者提供了可信的更新源：

1. 点击“配置发布源”。
2. 填写发行者提供的 **HTTPS 发布清单地址**与 **Ed25519 公钥（PEM）**，点击“信任此来源并保存”。这里填写的是公钥，不是登录密码、API key 或私钥。
3. 点击“检查更新”。配置后也会按周期自动检查，默认间隔为 24 小时。
4. 出现可用版本后，点击“安装更新”，阅读并确认提示。Bridge 会校验更新包并重新启动，保留设置。

自动激活更新适用于安装版。便携版请使用发行者提供的新完整便携包。更新失败或激活中断时，安装版会尝试回滚并关闭背景；确认恢复正常后再手动启用。

### 卸载

先通过托盘选择“退出并恢复”，再到 **Windows 设置 → 应用 → 安装的应用 → Codex Wallpaper Bridge → 卸载**，确认提示。

卸载会清理 Bridge 的安装文件、启动项和快捷方式，保留 Bridge 偏好与日志，以及安装目录中用户自行添加的文件。Wallpaper Engine 壁纸和官方 Codex 文件不会被删除。

便携版可先关闭开机启动并保存，再“退出并恢复”，随后移除其解压文件夹；Bridge 的本地数据仍会保留。

## 10. 当前兼容范围

本版本实机验证环境为 **Windows 11 x64（26200）、Codex 26.1007.9446.0、Wallpaper Engine 2.8.0.42**。其他版本会进行兼容检查，不能据此推定全部支持。

| 壁纸类型 | 当前使用边界 |
| --- | --- |
| Video | 使用 Codex 自带解码器；格式支持取决于该解码器。保留源视频编码和分辨率，实际显示受窗口及渲染尺寸限制 |
| Scene | 已验证上述 WE 版本的 D3D11 路径；浮点画面会转换为 SDR，HDR 高光可能裁切，不保证 HDR 原样呈现 |
| Web | 在隔离的静音 Edge 中运行；常见 HTML/JS 与普通属性可用，部分 WE 音频可视化、媒体、随机文件和查询等专属接口尚不支持 |
| Application | 采集当前 WE 启动、与所选 EXE 一致且能明确识别的已有窗口；任意 Unity、多进程或多窗口项目尚未全面验证 |

物理跨屏 DPI、干净账户环境和长期四窗口运行仍有待扩展验证。遇到不兼容项目时，Bridge 会恢复官方外观，避免持续覆盖异常背景。
