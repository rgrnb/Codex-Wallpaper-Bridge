# Codex Wallpaper Bridge 使用说明

**本机自用收尾已完成。** 最新186项检查、恢复验证及未完成范围见[收尾记录](CLOSEOUT-0.3.0.zh-CN.md)。下述179项/耐久数字为此前历史证据。未公开发布或正式安装；多屏、全天与扩展不作本次完成门槛。

更新于2026年10月19日。本文介绍 **0.3.0 本机验证候选**，未公开发布。179项测试、语法、六来源双窗与真实最大化/还原合成检查通过；3735.771秒单屏耐久包含9Video、4次Sheep、跨卷Scene和24轮切换，资源门槛、42个worker/36个runtime回收及原资源/环境保持通过。新包验证状态见[收尾记录](CLOSEOUT-0.3.0.zh-CN.md)，历史32项非Video矩阵、685秒记录、0.2.4和早期候选保留。

Bridge 为 Codex 单独选择壁纸，桌面 Wallpaper Engine 的选择、参数和音量保持原样。旧版“跟随桌面”模式已移除。

## 启动与选择

1. 从旧 Bridge 的托盘选择“退出并恢复”。使用完整的程序目录；开发源码应统一构建，已有 0.2.4 包只能代表其历史能力。
2. 打开“壁纸库”，按名称搜索、类型筛选或刷新。程序读取 Steam 多库、创意工坊、WE 内置和本地项目；默认先加载封面。
3. 选择项目，阅读右侧播放方式与限制，再点击“设为 Codex 壁纸”。不兼容的引擎或应用会给出具体原因；列表可见不代表已经支持播放。
4. 需要连接时，在“状态与维护”点击“以连接模式启动 Codex”。这会使用 Bridge 的独立客户端配置，不复制原登录资料；首次可正常登录。连接仍受版本列表和页面结构检查约束，候选适配器开关不是正式兼容证明。

新安装默认关闭背景和自启动。首次升级不会把桌面壁纸自动导入 Codex；应用可播放项目后才保存选择并启用背景。

## 构图与属性

每张壁纸保存自己的等比铺满、1–4 倍缩放和水平/垂直位置。界面用 0–100% 表示位置，中点为 50%。整个窗口共用一张画布，侧栏、顶栏和主区域不分别缩放。

布尔、数字、颜色、选项和文本属性按项目元数据生成。文件属性使用“选择文件”，目录属性使用“选择文件夹”；路径框只读。“清除”保存显式空路径。作者提供的默认路径不授予外部文件访问；只有明确选择并保存后才会使用相应授权，保存时还会检查文件/目录是否存在及类型是否正确。

属性作用于 Bridge 的独立来源，不写桌面配置。各项目作者和渲染接口决定具体效果，不保证所有属性有效。视频直接解码时主要使用构图与背景效果，不执行场景或网页脚本。

“显示与性能”的效果仅作用于背景。默认不透明度、亮度、对比度为 100%，模糊为 0；原有保存值会保留。输入框、发送、语音、附件和会话选中态保留原有交互。切换有效来源等待首帧后做320ms渐变；加载失败撤销Bridge效果，恢复Codex原貌并报告错误。

## 播放与声音

Codex 壁纸以独立静音方式运行，不使用桌面 WE 的全局静音、暂停或壁纸切换来实现。

| 类型 | 当前开发路径 | 使用边界 |
| --- | --- | --- |
| 视频 | Codex Chromium 直接读取原文件，赋 `src` 前静音，保留原始尺寸 | 实际流畅度受来源与系统负载影响；不以逐帧截图代替正常解码 |
| 场景 | 已核验WE2.8.0.42 x64，启动前私有禁声；29个Scene历史矩阵保留，新增跨卷自绘Scene已通过当前Codex双窗与清理 | 引擎/素材分卷时需素材父目录可写且支持硬链接；原素材不复制，任意项目、文件系统、引擎/GPU兼容性未保证 |
| 原生网页 | 私有静音 WE 保留原生接口，鼠标走自有 CEF 的 loopback CDP | 严格检查自有进程、Job 和文档身份；不保证所有作者或硬件专属功能 |
| 兼容网页 | 隔离静音 Edge，提供真实频谱、系统媒体信息、文件/目录与随机文件、目录变更及 FPS/暂停回调 | 未覆盖接口明确报告不可用；系统当前没有媒体会话或声音时不会编造数据 |
| 应用 | 仅审核Sheep / Unity2017.2.0f3，启动前私有禁声；640×360、5次点击、动态/音频定向通过，实体双窗与循环中的4次应用切换/隐藏重建通过 | 系统光标/前台、原素材/桌面配置保留；其他应用继续拒绝 |

“动态预览”只对通过当前启动检查的项目开放，使用独立来源；关闭窗口或点击“关闭预览”释放资源。预览成功不等于当前版本已经通过所有项目、物理双窗或耐久验收。

## 鼠标交互

Bridge 可以观察 Codex 背景上的受信鼠标移动与左键点击，并按当前构图映射到独立来源。它不拦截聊天、不读取聊天内容、不转发键盘、拖拽或修饰键。窗口隐藏、失焦、输入过期或来源代次变化时会丢弃输入。

Scene、原生/兼容 Web 和审核 Sheep 的鼠标路径已有定向实测，不通过移动系统光标或切换用户焦点来实现。Sheep 的尺寸/DPI 问题已修复，实际交互使用私有轮询输入；没有焦点 hook 或窗口激活通知。仅发送窗口鼠标消息的对照未产生新羊，因此不能把普通消息发送等同于 Unity 交互支持。该结论只限审核 Sheep，仍需最终构建和真实 Codex 集成回归。

## 帧率、多窗口与恢复

FPS 有 30、60、120 和自动四档，默认 60。性能模式上限 30；平衡和画质模式上限 120。自动档按检测到的显示刷新率及实际 Bridge 负载调整，上限仍为 120。设置值是上限，不是对任意项目的帧率保证。

多个 Codex 窗口共享独立 Scene、Web 或 Application 图像来源，各窗口按自身尺寸绘制；视频由每个客户端独立解码。所有窗口不可见时停止传帧并释放自有来源，恢复后重建，不暂停桌面壁纸。

捕获失败恢复Codex原貌，按2/4/8/16/32/60秒最多重试六次，之后等待环境变化或手动重试。正常退出先移除背景；停止超时会报告并保留自有资源供重试，确认退出后才清理。控制器异常退出后页面租约恢复外观，自有Job和进程身份检查用于回收独立任务。

关闭管理界面只隐藏到托盘；完全退出使用“退出并恢复”。“随 Windows 登录启动”由用户自行勾选。

## 数据、诊断与卸载

数据逻辑位置为 `%LOCALAPPDATA%/CodexWallpaperBridge`，MSIX 环境可能映射到 LocalCache。`codex-profile` 是独立客户端配置，不应当作普通缓存删除。诊断导出不包含聊天、登录资料或工作文件。

“状态与维护”提供恢复官方外观、诊断导出、连接启动与更新设置。默认没有公共更新源，开发包没有发行者代码签名；更新继续使用签名、哈希、健康检查和失败回滚机制。

安装版从 Windows“已安装的应用”或开始菜单卸载；便携版运行包内 `Uninstall.exe`。卸载保留个人数据和安装目录内用户新增文件，不删除 Steam 壁纸；文件占用或清单异常时保留入口供重试。详见 [卸载说明](UNINSTALL.zh-CN.md)。

## 验证范围

当前管理 UI 在 96 DPI 虚拟化和本机实际 144 DPI 各通过 126 项 fixture 检查及屏幕实拍，包括性能/FPS 选择、文件/目录属性与最小窗口布局。本机只有一块物理显示器，这不是跨屏测试。

0.2.4在旧Codex上的证据保持历史范围。本轮179项测试、六来源双窗、真实最大化/还原及3735.771秒耐久，以及历史29Scene/2Web/Sheep矩阵见[验收记录](ACCEPTANCE.zh-CN.md)。旧失败报告分别保存；一小时不证明全天、跨显示器或未知应用支持。开发依赖见[README](../README.md)，完整PRD状态保持false。

开发验收应先退出其他 Bridge 控制器。只有用户已授权临时环境操作时才使用 `scripts/independent-environment.ps1`；脚本按实际基线处理桌面活动并在结束后核对恢复。管理 UI fixture 不能与物理 Codex 窗口验收同时运行。
